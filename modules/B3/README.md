# B3. Procurement and tenders

> **Outline.** The material of this module is being written by the Showcase and Certification Working Group. The objectives, outline and assessment below are the agreed scope for program version 2026.1.

6 class hours. Assessed by: case study.

## Learning objectives

After this module you can:

1. Write requirements for a Verifiable Trust deployment that are testable and vendor-neutral.
2. Evaluate a bid: compliance matrices, demonstrations to request, red flags.
3. Align a tender with public-sector frameworks (eIDAS 2, national digital identity programs, open-source policies).
4. Price and phase a procurement: pilot on the test network, production on the main network.

## Prerequisites

C1, C2, and the reduced B4 reading.

## Outline

### 1. Requirements

Functional (services, wallets, ecosystems, credentials), non-functional (security, availability, data protection), conformance (specifications, harness); what to leave open.

### 2. Evaluation

Compliance matrices; proof points to require (a trusted DID, a conformance run, a governance framework); scoring; red flags such as proprietary registries.

### 3. Public-sector alignment

eIDAS 2 and the EUDI wallet; national programs; open-source and open-standard clauses; data residency.

### 4. Phasing and pricing

Pilot, production, operations; what the Foundation provides and what vendors provide; where fees and deposits appear in a budget.

## Assessment

Case study: a requirements section and an evaluation grid for a tender described by the certificator.

## Reading list

The Foundation's tender language kit. eIDAS 2 regulation overview. Module B4 sections on liability and licensing.
