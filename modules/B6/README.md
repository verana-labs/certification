# B6. Running an ecosystem

> **Outline.** The material of this module is being written by the Showcase and Certification Working Group. The objectives, outline and assessment below are the agreed scope for program version 2026.1.

6 class hours. Assessed by: case study.

## Learning objectives

After this module you can:

1. Author a complete governance framework from the Council template and anchor it.
2. Run onboarding operations: evidence lists, validator staffing, service levels, pending tasks.
3. Handle disputes, appeals, revocations and slashing with a record that holds up.
4. Audit participants and the ecosystem itself; report to the ecosystem's governing body.

## Prerequisites

C3, and T4 or B1.

## Outline

### 1. Authoring the framework

From policy to sections; evidence requirements per role; fees and slashing tables; versioning and notice; publishing and anchoring.

### 2. Onboarding operations

Staffing validators; evidence over vt-flow; turnaround commitments; pending tasks in the frontend; renewals.

### 3. Disputes and enforcement

Complaints, investigation, hearing, decision; ending versus revoking; slashing with evidence; appeals.

### 4. Audits and reporting

Sampling participants; conformance of issuers and verifiers; metrics for the governing body; the annual review.

## Assessment

Case study: a governance framework and an operations plan for an ecosystem described by the certificator; the Verana Certification Ecosystem's own policy is the model.

## Reading list

Verana Council governance framework templates. The Verana Certification Policy. docs.verana.io: Build, Ecosystems.
